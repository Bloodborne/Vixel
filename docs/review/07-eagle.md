# 对标 Eagle：哪些值得吸收

调研对象：Eagle 4.0（eagle.cool，付费素材管理软件，macOS / Windows）。方法：读 Eagle 安装包里的全部 1915 条界面文案（`i18n/zh_CN.js`）反推功能清单，结合官方博客（2026-03 上线离线 AI Search、AI Action、MCP）。2026-10-11。

## 结论

Eagle 的护城河是**收集 + 手工组织**：浏览器扩展 / 截图导入、标签与标签群组、规则式智能文件夹、评分、动作自动化、上百种设计格式。
Vixel 的护城河是**零整理的检索**：多模态语义（图片 + 视频片段 + 声音）、图中 / 视频画面文字、人脸、片段级跳转。

Eagle 今年也有了离线 AI 搜索（只限图片，`preferencesWindow.aiSearch.*`），"本地语义搜索"本身不再是差异点。
最划算的路径不是复制它的收集链，而是把它的**轻组织层**（筛选、收藏、智能相册、相似清理）叠在 Vixel 的检索上，数据全部存在 Vixel 的数据库里，原文件保持只读。

## 决定（2026-10-11）

| 做 | 说明 | 对应 Eagle |
|---|---|---|
| 轻量标签（0.4） | 检查器里打标签（T 键、多选批量），侧栏标签视图，标签参与搜索和筛选 | `selectTagPanel.*` |
| 收藏（心形） | F 键切换；侧栏"收藏"；可作筛选条件。选心形而不是 1–5 星：照片用户很少用到多级评分 | `shortcuts.organize.rating.*` |
| 组合筛选 | 方向 / 分辨率 / 时长 / 人物 / 收藏 + 日期，与语义搜索叠加 | `filter.*`（约 18 种） |
| 智能相册 | 保存"查询 + 筛选"为侧栏常驻、自动更新的相册 | `modal.smartFolder.*`、`savedFilter.*` |
| 相似照片清理 | 用已有图片向量找连拍 / 导出副本，推荐保留项；"在 Vixel 中隐藏"或确认后移到废纸篓 | `duplicatePanel.*` |

| 暂不做 | 原因 |
|---|---|
| 读取 / 导入 Eagle 资源库 | 2026-10-11 决定不做：Vixel 定位是更强更好用的同类替代，靠自身功能取胜，而不是寄生在 Eagle 的资源库上（开发期做过只读读取，已移除） |
| 颜色筛选 / 调色板 | 设计师需求，照片用户少用 |
| 批量重命名、裁切旋转写回 | 违背"原文件只读" |
| 浏览器扩展、截图、自动导入 | 定位不同：Vixel 索引你已有的文件夹 |
| 动作自动化、MCP | 命令行（`--json`）已覆盖 Agent 场景，后续可做薄封装 |
| 多资源库、密码锁 | 价值低，后续看需求 |

## Eagle 功能清单（摘要）

- 组织：多级文件夹（封面、密码）、标签群组 / 合并 / 文件夹级自动打标签、规则式智能文件夹（约 25 种属性，AND/OR、正则）、1–5 星、注释与画面标注、来源 URL。
- 浏览：瀑布流 / 自适应 / 网格 / 列表；十余种排序；约 18 种筛选器（颜色、形状、尺寸、格式、评分、日期、标签、时长、相机……），可排除、可锁定。
- 搜索：关键字、快速切换文件夹、AI Search 插件（离线，语义 + 以图搜图，仅图片）、外部以图搜图引擎、保存筛选器。
- 查看：缩放 / 导航器 / 幻灯片、裁切旋转、拼图；视频逐帧、倍速、记住位置、取帧设封面、字幕；GIF 逐帧；自动调色板。
- 批量：模板化批量重命名；"动作"串联整理步骤；MCP 对接外部 AI。
- 重复：完全相同 + 视觉相似两种扫描，自动选保留项、合并元数据、报告节省空间。
- 导入：浏览器扩展、网页 / 屏幕截图、拖拽、监视文件夹自动导入、素材包导入导出。
- 资源库：多库切换合并、网盘同步冲突提示、密码锁 / Touch ID、回收站。
- 没有人脸识别；OCR 插件调用 Google 接口（非离线）。
