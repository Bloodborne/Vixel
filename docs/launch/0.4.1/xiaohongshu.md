## 正文

剪辑的人都懂：素材越攒越多，找的时候只能一个个点开拖进度条。

我做了个免费开源的桌面工具 Vixel，把素材文件夹原地索引完，直接搜：

🔍 打「火箭发射」，直接跳到视频里发射的那一秒
🖼️ 手里有张截图？拖进去，帮你找到它出自哪个视频的哪一段
✍️ 画面里出现过的字也能搜（招牌、字幕、白板都行）
🏷️ 标签自己长出来，还能按颜色筛
⌨️ 新版本：任何软件里按 ⇧⌘Space 直接呼出搜索，结果拖进剪辑软件就能用

重点是**完全离线**：AI 模型都打包在安装包里，素材一个字节都不上传，
没有账号、没有会员、没有算力费。代码全部开源（MIT），macOS 和 Windows 都有。

装的时候有一步要注意：安装包还没买签名，macOS 要在 系统设置→隐私与安全性 里点「仍要打开」，
Windows 在 SmartScreen 点「更多信息→仍要运行」。

GitHub 搜：RGB-loop/Vixel（Releases 里下载，v0.4.1）

视频里的素材都是公有领域的测试素材，你的素材长什么样它就能搜什么样～

## 评论回复预案

- 「收费吗？」——完全免费，开源的，代码都在 GitHub 上。
- 「会不会上传我的素材？」——不会，模型在你电脑上跑，断网都能用。不放心可以断网试。
- 「支持什么格式？」——常见图片视频音频都行，还有 PSD/PDF/AI/SVG 设计稿；RAW 也支持。
- 「M1 老 Mac 能跑吗？」——Apple Silicon 都可以；Intel Mac 暂时没有安装包。
- 「和 Eagle 比呢？」——Eagle 是付费的、要把素材导进它的库；Vixel 免费开源、不动你的文件夹，
  而且能按片段搜视频。各有侧重，可以一起用。
- 「安装包怎么这么大？」——600 MB 里大头是 AI 模型，装好就能离线用，不用再下载任何东西。
- 「有教程吗？」——装好 ⌘O 选素材文件夹，等索引跑完直接搜，没有别的步骤。
