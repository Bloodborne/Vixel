## 简介（置顶）

一句话找到照片和视频素材里的那一刻。完全离线：模型内置（EmbeddingGemma 2 · LiteRT），
素材不上传、无账号、无遥测。免费开源（MIT）。

⬇️ 下载（macOS Apple Silicon / Windows x64，约 600 MB，模型已内置）
https://github.com/RGB-loop/Vixel/releases/tag/v0.4.1

源码：https://github.com/RGB-loop/Vixel

Windows：SmartScreen → 更多信息 → 仍要运行

## 评论回复预案

- 「配置要求？」——Apple Silicon 的 Mac 或带 GPU 的 Windows x64；没有独显也能跑，自动退回 CPU。
- 「NAS / Linux？」——Linux 能编译但没测过，想要的去 GitHub issue +1。
- 「这不就是 Eagle？」——Eagle 付费、导入式、AI 搜索限图片；Vixel 免费开源、原地索引、能搜视频片段。
  两者可以共存，不打算做 Eagle 库导入。
- 「隐私怎么证明？」——断网用；或看源码 `enforceOfflinePolicy`；渲染进程网络请求整体被拦。
- 「为什么要 600 MB」——模型都在包里，换来的是第一次打开就离线可用。
