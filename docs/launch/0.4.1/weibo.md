## 正文（≤ 300 字）

做了半年的开源项目 Vixel 更新 v0.4.1。

它把你硬盘里的照片、视频、音频、设计稿原地索引，然后用一句话搜：
「火箭发射」直接跳到视频里发射的那一秒；截图里的字也能搜；拖一张图进去能反查它出自哪段视频。

新版本加了全局快捷键：任何应用里按 ⇧⌘Space 呼出搜索面板，结果直接拖进剪辑软件。

重点：完全离线。AI 模型打包在安装包里，没有账号、没有上传、断网可用。免费开源（MIT），
macOS（Apple Silicon）和 Windows 都有。

GitHub：github.com/RGB-loop/Vixel
（安装包未签名：macOS「仍要打开」、Windows「仍要运行」即可）
