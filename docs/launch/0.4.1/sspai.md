## 全文开头（可直接用）

我的照片库和素材盘加起来有几百 GB。过去十年，「整理」这件事我试过三次：建文件夹体系、
打标签、买付费软件，每次都坚持不过一个月。后来我意识到问题不在毅力——**整理本身就是不该存在的
成本**。你拍下一段视频的时候，并不知道三年后会用什么词去找它。

所以我花了半年做了 Vixel：一个免费开源（MIT）的桌面应用，把你现有的文件夹原地只读索引，
然后用自然语言去搜——「海边的日落」「宝宝第一次走路」「火箭发射」。视频按 32 秒一段编码
（画面每 4 秒一帧，连同声音），搜到的结果直接**跳到命中的那一段**，不用再拖进度条。
截图和视频画面里出现过的文字（PaddleOCR v5 + 结巴分词）、文件名、标签是另外几路召回，
一起做融合排序。库里真没有的东西，它会直说「没有特别突出的匹配」，而不是硬凑一屏。

与大多数「AI 相册」不同的是，这一切发生在你的电脑上：EmbeddingGemma 2 模型打包在安装包里
（这也是安装包有 600 MB 的原因），经 LiteRT-LM 跑在 GPU 上；没有账号、没有遥测，
渲染进程的网络请求在代码层面被整体拦截——你可以断网使用来验证这句话。

## 评论回复预案

- 关于准确率：引用评测集数字（demo top-1 1.00 / footage 0.94，`npm run eval` 可复现），
  并欢迎提供 bad case。
- 关于 Apple 照片：系统相册只管「照片图库」；Vixel 索引任意文件夹（含素材盘、下载目录），
  且视频按片段搜。两者不冲突。
- 关于订阅制软件的对比：Vixel 无任何付费点，也因此没有云同步——取舍说清楚。
