## 正文（即刻风格：短、第一人称、有数字有细节）

Vixel v0.4.1 发了。

这个版本最爽的功能：任何应用里按 ⇧⌘Space，呼出一个 Spotlight 式的面板搜整个素材库——
搜「火箭发射」，回车直接跳到视频里发射那一秒，⌘C 拷的是文件本身，拖进剪辑软件时间轴就能用。

其他值得一提的：

- 笔记本用电池 / 过热时，大批量索引自动让路，新文件照常即时可搜
- 爬虫学会了绕开密钥文件、node_modules、数据集目录，iCloud 云端占位文件绝不触发下载
- 搜索排序大修一轮，公开评测集上 demo 库 top-1 到了 1.00（评测脚本就在仓库里，npm run eval 可复现）
- 修了 Windows 退出残留进程和输入法抢键的 bug

还是那三件事：完全离线（模型内置，断网可用）、免费开源（MIT）、不动你的原文件。

macOS（Apple Silicon）+ Windows（x64）。安装包没签名，macOS 要「仍要打开」一下。

https://github.com/RGB-loop/Vixel

## 评论回复预案

- 「用什么模型？」——EmbeddingGemma 2，LiteRT-LM 跑在 GPU 上（Metal / D3D12），文字图片视频音频同一向量空间。
- 「为啥不做成 app store 版」——沙盒限制 + 签名成本，先把功能做扎实。
- 「能搜 PDF 吗？」——能，PDF/AI/PSD/SVG 按首页栅格预览索引，页面上的字也 OCR。
- 「跟 DigUp 像吗？」——同一个基础模型；Vixel 多了 Windows、中文分词、整理功能（人物/标签/相册/清理），
  而且模型随包、首启不下载。DigUp 文档类（PDF 全文、代码）覆盖更广。
