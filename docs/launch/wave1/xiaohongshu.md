## 正文

素材越攒越多，找一个镜头要翻半天？

Vixel 是一个免费开源的素材搜索工具：
把素材文件夹加进去，直接用一句话搜——
「海鸥喂小鸟」「火箭发射」「train arriving at a station」
打开就跳到命中的那一段，时间轴上标出来 ✨

📌 能做什么
· 用一句话搜视频、照片、音频（中英文都行）
· 画面里出现过的字也能搜
· 按时长、横竖、分辨率、人物筛选
· 收藏 + 智能相册，常用的搜索一键打开

🔒 隐私
· 完全离线，素材不上传
· 不用注册账号
· 直接用你原来的文件夹，不搬文件、不改文件

💻 macOS（M 系列芯片）/ Windows
🔗 GitHub 搜「RGB-loop/Vixel」，Releases 里下载

小提示：安装包还没签名，Mac 第一次打开会被拦，去「系统设置 → 隐私与安全性」点「仍要打开」就好。

用 Eagle 管图片的朋友，可以拿它补上视频素材的搜索～
