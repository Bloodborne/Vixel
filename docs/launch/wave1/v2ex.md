# V2EX ·「分享创造」

节点：分享创造（/go/create）。发帖后 2 小时内作者在线回复。

## 标题（三选一）

1. 做了个免费开源的离线素材搜索：一句话找到视频里的那一秒
2. 视频素材太多找不到镜头？写了个本地 AI 搜索工具，搜「火箭发射」直接跳到那一段
3. 开源｜Vixel：照片 / 视频 / 音频的本地语义搜索，完全离线、不用账号

## 正文

> 位置：开头放 GIF（`video-search.gif`，搜「火箭发射」→ 打开 → 时间轴高亮命中的那一段）。V2EX 不能直接传图，先传到图床或用 GitHub 仓库里的地址。

硬盘里攒了几百个视频素材，每次剪片子要找「那个海鸥的镜头」，只能一个个点开拖进度条。文件名是 DJI_0504.MP4 这种，什么也看不出来。

所以写了 Vixel：把文件夹加进去，它在本机把画面、声音、画面里的字都建好索引，之后用一句话搜就行：

- 搜「海鸥喂小鸟」「火箭发射」，直接打开到命中的那一段（视频按片段索引，时间轴上标出来）
- 画面里出现过的字也能搜（招牌、片头字幕）
- 中文、英文都能搜；也能按时长、方向、分辨率、人物筛选
- 照片、RAW、音频同样支持；还有人物、离线地图、相似照片清理

几点和别的工具不太一样的地方：

- **完全离线**：模型随安装包分发，第一次打开也不下载任何东西；界面里的网络请求是被代码拦掉的。没有账号，没有遥测。
- **不搬文件**：直接索引你现有的文件夹，原文件只读，不导入、不复制、不改名。
- **免费开源**（MIT）。

如果你在用 Eagle：它的 AI 搜索是针对图片的，Vixel 可以拿来搜视频素材，两个一起用不冲突。

下载（macOS Apple Silicon / Windows x64）：https://github.com/RGB-loop/Vixel/releases/latest

### 实话说几个局限

- 安装包约 600 MB，因为模型打包在里面。
- **没有签名**（没买 Apple / 微软的证书）。macOS 第一次打开会被拦，到「系统设置 → 隐私与安全性」点「仍要打开」，或者执行 `xattr -dr com.apple.quarantine /Applications/Vixel.app`；Windows 在 SmartScreen 里点「更多信息 → 仍要运行」。介意的话可以从源码编译。
- 首次索引需要一段时间，在后台慢慢跑，期间可以正常浏览。
- 视频画面里的文字目前只识别每个视频的代表帧；长视频的人脸也只看首帧。
- Linux 能编译但我没测过。
- 演示用的素材都是 Wikimedia Commons 上的公有领域 / CC0 视频。

想听听大家的意见：你的素材一般怎么管？最想用一句话搜到什么？遇到搜不准的例子也欢迎贴出来，我拿来调。
