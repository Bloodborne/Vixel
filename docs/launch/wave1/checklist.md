## FAQ（回复时用自己的话说）

**为什么安装包这么大（约 600 MB）？**
语义模型、文字识别、人脸模型都打包在安装包里，装好就能离线用，第一次打开也不用再下载。

**为什么没有签名？会不会有问题？**
签名证书要付费，现在还没买。代码完全开源，可以自己看、自己编译。macOS 放行：系统设置 → 隐私与安全性 →「仍要打开」，或 `xattr -dr com.apple.quarantine /Applications/Vixel.app`；Windows：SmartScreen 里「更多信息 → 仍要运行」。

**真的不联网吗？**
模型都在本机运行；界面发起的网络请求在代码里是被拦截的（地图也是打包好的离线底图）。没有账号、没有统计上报。可以断网验证。

**支持什么格式？**
图片 jpg / png / webp / heic / avif 等，RAW（cr2 / cr3 / nef / arw / dng / raf / orf / rw2），视频 mp4 / mov / m4v / webm / mkv / avi，音频 mp3 / m4a / wav / flac / ogg 等。内置播放器放不了的编码可以用系统播放器打开，不影响搜索。

**会改我的文件吗？**
不会。原文件只读；收藏、相册、隐藏都存在 Vixel 自己的数据库里。只有「清理相似照片」里你确认之后，才会把文件移到废纸篓（可以从废纸篓恢复）。

**和 Eagle 有什么区别？**
Eagle 是很成熟的素材收集和整理工具（浏览器扩展、标签、很多设计格式），它的 AI 搜索针对图片。Vixel 不导入文件，直接索引原来的文件夹，强项是视频：按片段搜画面和声音、直接跳到那一段。两个可以一起用。

**和 Immich 有什么区别？**
Immich 需要自己搭服务器，适合多设备同步和手机备份。Vixel 是桌面应用，装上就能用，不需要服务器。

**支持 Linux / Intel Mac 吗？**
Linux 能编译但还没测过；Intel Mac 目前没有安装包。需要的人多的话会补上，可以在 GitHub issue 里说一声。

**搜得准吗？**
在演示库上大部分查询第一条就是对的；没有把握时会直接提示「没有特别突出的匹配」，不会硬凑结果。搜不准的例子欢迎发给我。
